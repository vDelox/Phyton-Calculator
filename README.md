# Python Calculator

A simple command-line calculator written in Python. This project was created as a beginner-level practice project to learn and improve fundamental Python programming concepts.

## 📌 About

This calculator allows the user to enter two numbers and choose an arithmetic operation to perform.

The project includes several basic mathematical operations:

* Addition (`+`)
* Subtraction (`-`)
* Multiplication (`*` / `.`)
* Division (`/` / `÷`)
* Exponentiation (`**`)
* Modulo (`%`)

The calculator also includes basic error handling for division and modulo operations when the second number is `0`.

## 🛠️ Concepts Used

This project helped me practice:

* Python functions
* `while` loops
* `if / elif` conditional statements
* User input with `input()`
* Integer conversion with `int()`
* Returning values with `return`
* Basic arithmetic operators
* Simple error handling

## ▶️ How to Run

Make sure Python is installed on your computer.

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project directory:

```bash
cd <repository-folder>
```

Run the calculator:

```bash
python calc.py
```

## 💻 Example

```text
Type first number: 10
Type second number: 5
Tell me what operation to use: *
```

```text
Type first number: 10
```
